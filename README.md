# U2-ejercicio26
# Controladores de Impresión y Periféricos

**Objetivo principal:** desarrollar un sistema de gestión de impresoras en Java utilizando clases abstractas y herencia para representar diferentes tecnologías de impresión.

El ejercicio implementa una clase abstracta `Impresor` y dos clases concretas: `ImpresoraLaser` e `ImpresoraTinta`. Cada impresora administra sus propios consumibles y valida su disponibilidad antes de realizar una impresión.
